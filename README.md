This is an experimental implementation of a "Kleene" [CCHM] cubical
type theory,[^cchm] with the interval taken to be the free Kleene
algebra rather than the free De Morgan algebra, as suggested in the
remark in §3 in the CCHM paper.

The implementation is heavily based on András Kovács' work; in
particular [elaboration-zoo] [^elaboration-zoo] (04 for basic implicit
arg support), [cctt] [^cctt], and [smalltt] [^smalltt].

There are no new ideas in the implementation, I think.

kleenextt implements a "[CHM]"[^chm-hits] variant of CCHM, with
`hcomp` and `transp` primitives as suggested in §3.4 there. The intent
is to closely match [Cubical Agda][cubical-agda] [^cubical-agda], but
I haven't checked to what extent this is true. In particular we do
also use [ghcomp](https://github.com/agda/agda/issues/3415).

kleenextt includes a built-in "hlevel" tactic which fills any cube
given an h-level proof. The implementation is based on KANG Rongji's
[extend] [^extend] (unfortunately still not merged in Cubical Agda as a
tactic.)

The [examples](./examples) contain some definitions adapted from prior
[cubicaltt] [^cubicaltt] and [cctt] [^cctt] examples, and from the
"[Cubical]"[^Cubical] [Cubical Agda][cubical-agda] [^cubical-agda]
library.

See also [REFERENCES.md](./REFERENCES.md) for a (somewhat) more
complete list of references.

Goals:

- [ ] Be much simpler than [Cubical Agda][cubical-agda]
      [^cubical-agda] but more usable than [cubicaltt] [^cubicaltt]:
      usable enough to comfortably write "Brunerie-number" examples
      without postulates.
- [x] Be fast enough to check my [computational proof that
      $`\pi_4\mathbb{S}^3`$ is
      nontrivial](./Kleenextt/Examples/Pi4S3.lean). It seems hopeless
      to compute this example in Cubical Agda today. It might be
      feasible to compute an analogous example in `cctt`, but I never
      managed to do it.
- [x] Don't be written in Haskell.

## How to try it

- Get `lean` and `lake` e.g. [this
  way](https://lean-lang.org/install/) or [this
  way](https://lean-lang.org/install/manual/)
- `make` (or `lake build`) builds the executable in
  `./.lake/build/bin/kleenextt`; you might `export
  PATH=$(pwd)/.lake/build/bin:$PATH`.
- `kleenextt check examples/Pi4S3.ktt` to check one file.
